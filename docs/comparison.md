# How this compares

Other open-source SEO/GEO skill collections are worth knowing. This page only states what
we could check in each repo's public README on the date below. It carries no star counts or
rankings, because they change daily; look at the repos.

Last checked: 2026-11-05. Corrections welcome via an issue.

Where they are broader: several of them cover more sub-tasks (e.g. local SEO, reporting,
more specialised agents) than we do. If you need that breadth, use them; the skills are
compatible and can sit side by side.

What we aim to do well: a single "optimize my website" entry point, evidence-tagged advice
you can check, and an honest boundary — everything in the audit is free, and live
AI-citation data (which a static audit cannot provide) is the one place we point to our
own product.
